## پوشش بررسی

- ثبت رزرو، قیمت و تخفیف، ظرفیت روزانه، رزروهای هم‌زمان، درخواست تکراری، تأیید/رد/لغو/انقضا، قرارداد ثابت و تغییر اقامت با رضایت مسافر.
- پذیرش، واحدهای فیزیکی، مسدودسازی، ثبت ورود/خروج و عدم حضور؛ پنل مدیر، هاستل‌دار و مسافر.
- تست جدید ۱۵ عملیات در سه نقش مهمان، مسافر و هاستل‌دار نامرتبط؛ نتیجهٔ درخواست و عدم تغییر داده هر دو بررسی می‌شوند.
- انتشار و پیش‌نمایش ملک، نظرات، مقاله‌ها، نقشه، تصاویر، حساب‌ها و نشست‌ها، بازیابی رمز و تأیید ایمیل.
- دیتابیس رابطه‌ای SQLite/libSQL، کلیدهای خارجی، مهاجرت، بازگشایی دیتابیس، تراکنش و rollback، بکاپ رمزگذاری‌شده و صف اعلان‌ها.
- نمایش فارسی، انگلیسی، روسی و ارمنی؛ دارک مود، عرض‌های موبایل و دسکتاپ و سناریوهای WebKit آیپد در workflow موجود.

## اعتبارسنجی

`npm test`: هر ۱۴۳ تست موفق. چهار تستِ مربوط به رزرو، اجاره و شناسهٔ نظر ابتدا روی نسخهٔ معیوب شکست خوردند و پس از اصلاح موفق شدند. شکست بازیابی بکاپ نیز جداگانه بازتولید و اصلاح شد.

`npm run lint` و `npm run build` موفق بودند. تست‌های افزوده‌شدهٔ مرورگر در `scripts/browser-smoke.mjs` و مجموعهٔ واکنش‌گرایی/WebKit در workflow `Browser and responsive audit` اجرا می‌شوند؛ نتیجهٔ اجرای مربوط به آخرین commit در Checks درخواست تغییرات ثبت است.

Chromium محلی با خطای `socket() failed: Operation not permitted` در process singleton محیط متوقف شد؛ برای آزمون کامل مرورگر از GitHub Actions استفاده می‌شود. این محدودیت محیط است و برای عبور از آن تنظیم امنیتی برنامه تغییر نکرد.

این بررسی تضمین نبودن تمام باگ‌ها یا تست بار نیست. سرویس واقعی ایمیل/ترجمه، تنظیمات Nginx/VPS و دستگاه فیزیکی آیپد در این نوبت قابل آزمون نبودند؛ تست اعلان‌ها از ارائه‌دهندهٔ شبیه‌سازی‌شده استفاده می‌کند. تغییرات نیازمند مهاجرت جدید دیتابیس یا متغیر محیطی جدید نیستند.
